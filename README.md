# X.goop.X.gop
misc circuit designs created in the process of developing the goopgop computer architectures in minecraft using the power grid circuit simulation mod

# Roadmap:
1. 1-bit computer (inspired by Usagi Electric's UE0 single-board tube computer)
2. 8-bit computer (bit-serial LU modeled after the MC14500B)
3. 16-bit computer (the Hack architecture from nand2tetris.org)
4. 32-bit computer (implement SERV, the world's smallest RISC-V compliant, bit-serial cpu)
